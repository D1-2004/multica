## 研究依据与取舍

- [Claude Code MCP](https://code.claude.com/docs/en/mcp)：连接状态与工具执行分开；
  远程断线采用有界指数退避，提供显式 reconnect；刷新工具目录失败不清空上次有效目录，
  同会话可以获取新工具。采用显式恢复与错误分类，不照搬其后台长驻客户端。
- [Codex MCP](https://learn.chatgpt.com/docs/extend/mcp?surface=cli)：必需/可选服务器分开，
  启动与业务调用超时分开，默认启动预算10秒，可选目录有短宽限。采用独立发现预算，
  不把业务调用45秒缩短成发现预算，不把权限必需性等同于外部连接健康。
- [OpenCode MCP](https://opencode.ai/docs/mcp-servers/)：工具发现默认5秒，并有独立OAuth入口。
  借鉴有界发现和认证单独恢复；采用较保守的10秒，不照搬5秒。
- GawkBot 固定 `71e82a1809565281cbd0bf8185d3c125b715d934`：本机 mcp-team broker 注册
  本地能力，与外部业务依赖隔离。沿用前轮来源映射。

正常 Pi 初始化会冻结其工具集，当前模板不具备目录动态更新接线。本轮不声称复刻
Claude 的动态注册，也不重建镜像：只在故障目录中暴露本地恢复入口与恢复调用入口。
后者把明确指定的工具名/参数交回同一原生 `tools/call` 路径，复用全部授权/写入门禁。
这是用户明确要求的兼容恢复边界，不新建业务权限或通用RPC入口。

## 合同与状态

健康：首页面10秒内成功，仍返回原生业务工具；调用预算、工具内容和授权不变。
故障：返回诊断、`multica_recover_connection`、`multica_call_recovered_tool`。
恢复：模型显式发起只读恢复（整体30秒、全部页、循环检测、总响应2MiB），
成功返回完整当下授权工具定义；随后通过恢复调用工具显式执行所需工具，逐次重新授权。
不自动重放任何业务动作；恢复目录成功只代表目录可用，不代表业务执行成功。
重连失败返回安全类别/需重新授权提示，仍可完成无关工作。
自定义连接器恢复目录保留上游原名（名字是调用参数，不进入Pi复合工具名），避免恢复后
调用长名字工具又为解别名重复发现。官方连接器仍返回呈现名字并走原有pin/alias门禁；
健康原生目录和原生别名调用保持原样。

不持久写 disabled、不共享凭证跨场域、不持久缓存“不可用”。保留现有OAuth刷新和
400/404会话重建。刷新本身仍在原有独立30秒事务内完成；等待者可按发现预算退出，
不取消正在完成的单次刷新，不对同一失效token重复请求。共享flight读取冻结的credential快照。

保留：无效本地配置、未知错误、父取消、授权/限流/审计失败均拒绝。
已知远端协议/格式/保留名字冲突拒绝该页的业务定义，但以显式故障目录隔离该连接器，
不提供非法business schema。修订 R2：同样覆盖后续页的已知故障；已验证的早期页定义可
由客户端保留，故障响应的 `_meta` 和诊断工具明确目录不完整，不把缺失工具当作无权限。
采用Claude保留有效定义的边界，不声称完整目录；每次业务调用仍重新授权。
显式恢复必须先收齐、校验全部页才返回 complete/available，不返回部分定义。
直配远程MCP/stdio的生命周期仍属Runtime，不在本次后端连接器恢复范围；不宣称它们已修。
