本次修复的通用机制：旧目标来自已读取的可信事项证据；审查对每项工作分别判断交付物数量和 target_match。允许做事与允许续接某个旧任务是两项独立检查。Host 校验结论、引用、身份和幂等，不通过“在吗”、人名或编号的关键词匹配判断意图。

额外 Host 协议检查包括：intent 与 basis 混淆的修复不改变任务授权；缺失/未知 target_match 不放行；different_deliverable 不能允许续接；未加载旧目标不能放行；失败读取不能覆盖已加载证据；按消息来源保留身份；混合窗口、忙碌补充及重复消息去重。
